# 给家长：给 Windows 安装英语自然语音（让发音更好听）

孩子听清、愿意跟读，声音自然很重要。软件会优先用 Windows 里带「Natural / Neural」的英语自然语音朗读。装一次即可，免费。

## Windows 11 / Windows 10 安装步骤

1. 打开「设置」（键盘按 Win + I）。
2. 点「时间和语言」→「语言和区域」。
3. 点「添加语言」，找到并选择 **English (United States)**（英语 美国），按提示添加。
   - 如果已经有 English (United States)，点它右边的「…」→「语言选项」，继续下一步。
4. 展开 English (United States)，点「语言选项」。
5. 找到「语音」一栏，点「添加语音」，选择名字里带 **Natural** 的语音（例如 Aria / Jenny / Ava 等，具体以列表为准），按提示安装。
6. 安装完成后，重新打开小狗英语，再到「更多」→「刷新声音列表」，软件会自动优先使用自然语音。

## 装完软件没自动识别怎么办

到软件右上角「更多」→ 朗读声音下拉框里手动选一个带 Natural 的声音；若列表没刷新，先点「刷新声音列表」。选择后会立即生效并记住，下次打开还是这个声音。

## 说明

- 自然语音是 Microsoft 提供的系统功能，安装免费，装一次即可，不需要在软件里额外付费。
- 不装自然语音也能用：软件会退回普通的英语声音（如 David / Zira）朗读，不影响学习；只是声音机械一些。
- 如果系统里连英语语音包都没有，软件会明确提示您按上面步骤安装，不会静默无声。
- 本软件不使用网页朗读方案，全是 Windows 原生语音，离线可用。
