# 小狗英语 · 家长安装与使用说明

## 一、安装（三步，全程不用装任何开发环境）

1. 打开本项目的仓库 Releases 页（GitHub 上 `xiaogouyingyu` 仓库右侧 Releases）。
2. 下载最新的安装包 `小狗英语Setup-x.y.z.exe`（`x.y.z` 是版本号）。
3. 双击安装包，按提示点「下一步」完成安装。

安装过程不弹管理员权限提示（装在您自己的账户目录），桌面和开始菜单会出现「小狗英语」图标，双击即可打开。

> 家长不需要安装 .NET、Inno Setup 或任何工具，也不需要命令行。编译打包都在 GitHub 云端自动完成。

## 二、日常使用

- 打开后是一张卡片，一次只学一个词。默认「整体读音」模式，点「▶ 播放」听发音。
- 顶部四个模式按钮随时切换：整体读音 / 拼读 / 看中文背英文 / 看中文+听音默写。
- 卡片上方有「正常 / 慢速」两个按钮（慢速适合孩子听清），「🔍 查词」按钮用浏览器打开释义网站。
- 孩子输入英文后按回车即可判定；答错会保留输入并全选，可直接改后重交。
- 底部有「上一张 / 跳过 / 下一张 / 标记掌握」。一轮学完会显示小小结。
- 低频功能都在右上角「更多」里：选朗读声音、学习统计、导入/导出词库、词库管理、备份/还原等。

## 三、升级（覆盖安装，数据不丢）

程序不会自动更新。以后有新版本时：到 Releases 页下载新的 Setup.exe → 双击 → 点「下一步」即可覆盖升级，**不需要先卸载**。词库、进度、音节修正、偏好设置都保存在您电脑的用户目录里，升级和卸载程序都不会删。

**升级后怎么确认数据还在**：打开「更多」，看版本号是不是新的，再看数据条数（词库条数、进度条数、待补充音节数）和升级前是不是一样。

**旧版绿色 exe 怎么办**：装好新版后，桌面/下载文件夹里旧的绿色 exe 可以手动删掉（删掉不影响学习数据）。安装程序不会自动扫描或删除您磁盘上的旧 exe，避免误删同名文件。

## 四、换电脑 / 换 Windows 账户

数据默认按 Windows 账户隔离：换另一个账户登录，看不到前一个账户的数据，这是正常现象。需要迁移时：在旧环境「更多」→「备份全部数据」得到带时间戳的 zip（存 backup 目录，界面会显示完整路径），把这个 zip 复制到 U 盘；在新环境「更多」→「从备份还原」选中它即可。还原前程序会先备份当前数据并校验版本，不会用旧备份直接覆盖较新的记录。

## 五、常见问题

- **没有声音 / 发音像机器人**：先装英语自然语音（见《家长安装自然语音说明.md》），装完到「更多」→「刷新声音列表」或手动选一个带 Natural 的声音。
- **词库想加新年级**：把符合格式的 md 文件（见 README 第 4 节）通过「更多」→「导入词库」导入即可，不用改程序。
- **导出的 md 和备份有什么区别**：「导出词库」只导词库文字，不含进度；「备份全部数据」含进度/音节修正/设置全部数据。想完整留存请用备份。
